# ENGRAM

[Скачать Developer Preview для Windows, macOS и Linux](https://github.com/Forem0/ENGRAM/releases/tag/v0.1.0-preview.1). В Windows ZIP есть приложение, CLI, документация и файл `START-HERE.txt`.

Нативное приложение на Rust для изучения цифровых следов в выбранных файлах и локальных резервных копиях. Фотографии, документы, возможные секреты и связи между находками — в одном рабочем пространстве.

**Developer Preview.** В первой версии есть рабочее ядро анализа и экспериментальные парсеры. Это не обещание восстановить любые удалённые данные и не доказательство того, что стороннее приложение читало ваши файлы.

## Что умеет эта версия

| Возможность | Статус |
| --- | --- |
| Ограниченное по объёму чтение выбранного каталога | Работает |
| Метаданные медиа и документов, связи точных копий | Работает |
| Поиск кандидатов на секреты в поддерживаемом тексте | Работает; значения скрываются до сохранения |
| Локальные дела JSON, повторное открытие и сравнение снимков | Работает |
| Индекс незашифрованной копии iPhone и сопоставление Photos | Экспериментально |
| Поддерживаемые базы Chromium, Safari и метаданные SMS | Экспериментально, если данные есть в источнике |
| Восстановление удалённых записей, Keychain, OCR и определение доступа приложений | Запланировано; пока не реализовано |

«Не сопоставлено с медиатекой» не означает «доказанно удалено навсегда». Найденная строка, похожая на пароль, не подтверждает, что пароль ещё работает. Отсутствие находок не доказывает отсутствие следов за пределами доступных данных.

## Запуск

Нужен Rust и обычные для вашей ОС инструменты нативной сборки. Подробности — в [BUILDING.md](docs/BUILDING.md).

```bash
git clone https://github.com/Forem0/ENGRAM.git
cd ENGRAM
cargo run -p engram-desktop -- --demo
```

Демонстрация использует сгенерированные тестовые файлы и настоящее ядро анализа. Личные папки автоматически не сканируются. Для реальной проверки выберите источник явно.

CLI использует то же ядро:

```bash
cargo run -p engram-cli -- doctor
cargo run -p engram-cli -- demo --out demo.engram.json
cargo run -p engram-cli -- fixture ./sample-source
cargo run -p engram-cli -- scan ./sample-source --out ./sample.engram.json
cargo run -p engram-cli -- inspect ./sample.engram.json --json
```

Выходной файл CLI должен находиться вне проверяемого каталога. Существующие файлы не перезаписываются.

## Как устроен интерфейс

Карта памяти показывает категории находок в форме мозга. Рядом — список и подробности выбранного объекта: путь, правило, доступные даты, хеш и связанные записи. Временная шкала помогает изучить наблюдаемые события. Сравнение показывает различия между двумя сохранёнными проверками. Экран модулей объясняет ограничения текущего источника.

Анализ работает локально без отправки данных в облако или ИИ-модель. ENGRAM не проверяет найденные учётные данные на сайтах, не обходит защиту ОС и не изменяет исходные базы. Однако дело содержит чувствительные метаданные: имена файлов, пути и URL. Не публикуйте личные дела вместе с отчётом об ошибке.
