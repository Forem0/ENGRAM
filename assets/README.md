# ENGRAM identity

The current 0.5.0 source extends Atlas Focus around the user's jagged cobalt-blue lightning creature. Graphite surfaces and cobalt controls frame a direct evidence-inspection workspace. The slogan is "Find what remains." and interface labels use Trace desk and Trace map. The paper artwork remains part of the brand history and the earlier released interface.

- `banner.png`: wide README header, 3:1 composition.
- `mascot.png`: square avatar with safe margins for a circular crop.
- `screenshots/`: actual native captures of the 0.5.0 Atlas Focus application, with explicit source/execution provenance and a labelled synthetic case.
- `design/atlas-focus/`: the selected interface design across all six views, with illustrative synthetic data. These original design illustrations are retained separately from the implemented interface and actual native captures.

Palette: background `#0B131D`, panels `#101C29`, raised panels `#142231`, text `#E7EEF9`, muted text `#A1B1C7`, dividers `#26394D` and primary cobalt `#1769FF`.

Category accents: media `#19C5C7`, secrets `#F4AA36`, documents `#A879F7`, browser `#318BFF`, messages `#E770C5`, location `#8D9AB6` and databases `#F2D66B`. Category accents remain distinct so source categories can be read independently of the active-control color. Paths and technical values use a local monospace stack; no remote fonts are loaded.

The selected creature is a brand illustration, not evidence or a screenshot of recovered data. Native application captures are separate from artwork and use synthetic source files processed by the Rust engine. The six workspace captures cover the map, findings, timeline, connections, comparison and module coverage. Their source revision and native execution evidence belong in [capture provenance](screenshots/README.md). Released packages retain the identity and provenance of their own build.

The README uses six actual **0.5.0 Atlas Focus native captures**, from [source 023d641](https://github.com/Forem0/ENGRAM/commit/023d64122c28e35fd8d84fcea9477d8f4f21710c) in the [successful native Tauri/IPC capture job](https://github.com/Forem0/ENGRAM/actions/runs/40766085166/job/123090713655). The [verification run](https://github.com/Forem0/ENGRAM/actions/runs/40768086711) records the related platform checks. The original [Atlas Focus design gallery](design/atlas-focus/README.md) remains a separate visual reference. The [0.4.0 release source](https://github.com/Forem0/ENGRAM/tree/v0.4.0/assets/screenshots) retains its native application captures and original provenance; the [0.3.0 source](https://github.com/Forem0/ENGRAM/tree/v0.3.0/assets/screenshots) preserves the earlier warm-ivory interface.
