# ENGRAM identity

Warm paper, charcoal ink, a small ochre archive tab. The brain is an archivist: curious, watchful, and focused on the evidence behind a memory.

- `banner.png`: wide README header, 3:1 composition.
- `mascot.png`: square avatar with safe margins for a circular crop.
- `screenshots/`: captures of the actual native application, labelled synthetic when using the demonstration case.

Palette: paper `#F4E9D2`, ink `#171815`, ochre `#C7932B`. The application uses the same restrained palette with category accents for navigation.

The brand illustrations were generated and iteratively refined for this project. They are concept artwork, not evidence or screenshots of recovered data. Keep documentation captures separate from illustrations.
