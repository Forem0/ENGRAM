# Atlas Focus interface design

The selected ENGRAM visual direction uses graphite surfaces, cobalt controls, readable file relationships and a persistent evidence inspector. This gallery covers all six workspace views.

These are design illustrations with synthetic example content. The workspace image is the maintainer-selected design, preserved unchanged; the other five views were generated with imagegen from that design and the corresponding implemented view as a functional reference. Illustrated filenames, relationships and counts are design content, not measured scan results or execution evidence.

This update publishes artwork and documentation only. ENGRAM 0.3.0 downloads retain their released interface. [Verified native application captures](../../screenshots/README.md) document the actual release, independently of this design gallery.
