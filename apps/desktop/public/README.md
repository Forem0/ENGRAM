# ENGRAM artwork

`mascot.png` is the bundled avatar for ENGRAM's user-selected jagged cobalt-blue lightning creature. It follows the identity described in the repository's `assets/README.md`. The interface uses this local asset without an external image request. Released packages retain the artwork and provenance of their own build.

`mascot-atlas.png` is the transparent-background adaptation used in the Atlas Focus application header. It was produced with imagegen from the existing mascot illustration, preserving the blue creature and removing its paper background. The original square artwork remains available. Both files are bundled locally; neither is evidence from an inspected source.
